# Project rules

## No AI or assistant references

Never mention Claude, Anthropic, AI assistants or AI-generated content anywhere in this repository or its history:

- **Commits:** no `Co-Authored-By` trailers, session links or "generated by" lines. Author and commit as the repository owner, never as an assistant identity.
- **Branches, tags, pull requests, issues and review comments:** no such references in names, titles or bodies, and no attribution footers.
- **Files:** none in code, comments, `readme.txt`, docs, changelogs, screenshots or `.wordpress-org/` assets.

This file is the one exception, and `.distignore` excludes it from the WordPress.org release.

## Project notes

- WordPress.org plugin `wp-smart-property` (released as EstateCraft from 3.0). Git is the source of truth; SVN is updated only by GitHub Actions (see `RELEASING.md`).
- Never push a git tag unless asked: a tag push triggers a live SVN deploy.
- The default branch is `master`. 2.0.x security fixes are on `release/2.0.1`; 3.0 is built on `release/3.0` (plan in `docs/ROADMAP-3.0.md` on `plan/3.0`).
- `vendor/` is not committed. `composer install` installs the test tools; PHPUnit needs `WP_TESTS_DIR` (see `bin/install-wp-tests.sh`).
